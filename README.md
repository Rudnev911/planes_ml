# Классификация военных и гражданских самолётов с помощью VLM

## Описание проекта

Практическая работа по дисциплине «Интеллектуальные системы и технологии».

Цель работы — исследовать возможности мультимодальных моделей искусственного интеллекта при бинарной классификации самолётов на военные и гражданские и сравнить качество их предсказаний.

## Используемые модели

- **SmolVLM2-500M**
- **SmolVLM2-256M**

Обе модели получены из Hugging Face и запущены локально с использованием GPU в Google Colab.

## Датасет

Для эксперимента подготовлено 30 фотографий:

- 15 гражданских самолётов;
- 15 военных самолётов.

Выборка включает как типичные, так и нетривиальные случаи, в том числе военные транспортные самолёты и другие типы воздушных судов, которые могут быть внешне похожи на гражданские.

## Результаты эксперимента

| Метрика | SmolVLM2-500M | SmolVLM2-256M |
|---|---:|---:|
| Accuracy | 96,67% | 80,00% |
| Precision (military) | 93,75% | 100,00% |
| Recall (military) | 100,00% | 60,00% |
| F1-score | 96,77% | 75,00% |
| Количество ошибок | 1 | 6 |

По результатам исследования SmolVLM2-500M показала более высокую общую точность классификации.

## Структура проекта

- `aircraft_classification_clean.ipynb` — исходный код эксперимента, анализ, графики и выводы.
- `aircraft_dataset_for_classmate.zip` — изображения самолётов и файл с разметкой.
- `evaluation_results.csv` — предсказания моделей.
- `model_metrics.csv` — итоговые метрики качества.

## Используемые технологии

Python, PyTorch, Hugging Face Transformers, Google Colab, Pandas, Scikit-learn, Matplotlib, Seaborn.

## Воспроизведение эксперимента

Откройте `aircraft_classification_clean.ipynb` в Google Colab, включите GPU, загрузите архив с датасетом и последовательно выполните ячейки ноутбука.

## Вывод

Эксперимент продемонстрировал возможность использования мультимодальных моделей для классификации самолётов по изображениям. Модель SmolVLM2-500M показала более высокое качество на исследуемой выборке, особенно при распознавании военных самолётов.

Из-за небольшого объёма выборки результаты не следует обобщать на все возможные изображения воздушных судов.
